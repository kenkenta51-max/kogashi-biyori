# こがし日和

焦がしバターフィナンシェの架空ギフトブランドを題材にした、スマートフォン向けECランディングページです。

**公開サイト:** https://kenkenta51-max.github.io/kogashi-biyori/

## 機能

- 商品紹介・贈るシーン・3つの味・開封体験
- メッセージ帯3色の選択と商品写真の切り替え
- 商品・配送案内のアコーディオン
- 数量変更、商品小計、デモカート、ローカル保存
- 購入エリアの表示に連動するスマートフォン用固定バー
- キーボード操作、ダイアログのフォーカス管理、動きを抑える設定への対応

## 技術

HTML / CSS / JavaScript。ビルド不要の静的サイトで、GitHub Pagesから配信しています。
スマートフォン用の1カラムを、PCでは最大480pxで中央表示します。
写真・背景はAI生成素材、Web上の見出し・説明・操作部品はHTML/CSS/SVGです。
日本語フォントはZen Maru Gothicをローカル配信しています。ライセンスは assets/OFL-Zen-Maru-Gothic.txt を参照してください。

## ローカルで表示

任意の静的HTTPサーバーでこのディレクトリを配信してください。Pythonがある場合は以下で表示できます。

```sh
python -m http.server 4174
```

## このサイトについて

ポートフォリオ用の架空ブランドです。商品・価格・配送条件は制作上の設定で、実際の注文・決済・問い合わせ送信は行われません。
